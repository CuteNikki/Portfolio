# 🎨 My Personal Portfolio

Welcome to the repository for my personal portfolio. This site serves as a showcase of my work, technical skills, and design philosophy as a full-stack developer and designer.

**🌐 Live Site:** [niso.moe](https://niso.moe)

## 🚀 Tech Stack

This project is built with modern web technologies focused on performance, type safety, and a refined user experience.

- **Framework:** [Next.js](https://nextjs.org/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Components:** [shadcn/ui](https://ui.shadcn.com/)
- **Runtime:** [Bun](https://bun.sh/)
- **Design:** [Figma](https://www.figma.com/) / [Adobe Creative Cloud](https://www.adobe.com/de/creativecloud.html)

## 🛠️ Features

- **Responsive Design:** Optimized for all screen sizes from mobile to ultra-wide monitors.
- **Dark Mode Support:** Built-in support for preferred color schemes.
- **Accessibility:** Built with a focus on easy-to-use, accessible experiences.
- **Dynamic Content:** Showcasing various projects and professional milestones.

## 🏁 Getting Started

To run the project locally, ensure you have [Bun](https://bun.sh/) installed.

### 1. Clone the repository

```bash
git clone https://github.com/CuteNikki/Portfolio.git
cd Portfolio
```

### 2. Install dependencies

```bash
bun install
```

### 3. Run the development server

```bash
bun dev
```

Open [http://localhost:3000](https://www.google.com/search?q=http://localhost:3000) with your browser to see the result.

## 📂 Project Structure

- `src/app/` - Contains the main routing and page logic.
- `src/components/` - Reusable UI components (including shadcn/ui).
- `public/` - Static assets like images and fonts.
